# CA Render Engine

> 连续细胞自动机（Continuous Cellular Automata）可视化引擎  
> 数学公式驱动 · 热切换配方 · 可视化编辑器 · 后处理特效

---

## 快速开始

```bash
pip install numpy scipy pygame asteval
python main.py
```

按 `H` 查看快捷键，按 `G` 打开可视化配方编辑器。

---

## 功能概览

| 功能 | 说明 |
|------|------|
| **60+ 数学公式模板** | 初始化图案、演化规则、颜色映射三大类 |
| **49+ 预设配方** | effects/ 目录下的 JSON 配方文件 |
| **可视化配方编辑器** | 三列面板交互式组合模板，实时预览，一键生成 |
| **加载界面** | 启动时显示 JSON 加载进度条和文件名 |
| **后处理特效链** | 辉光、边缘检测、运动轨迹、暗角、反色 |
| **颜色预设** | 9 种运行时颜色预设，`P` 键切换 |
| **自动播放** | 定时切换配方，约 10 秒/个 |
| **缩放** | 1× ~ 8×，`↑↓` 键调节 |
| **过渡动画** | 配方切换时 25 帧交叉淡入淡出 |
| **HUD 信息条** | FPS、步数、统计、特效指示 |
| **侧边栏** | 可滚动的配方列表，鼠标点击切换 |
| **截图** | `S` 键保存 PNG 到 screenshots/ 目录 |
| **循环重置** | 配方内配置 cycle 自动周期性重置网格 |

## 使用方式

```bash
# 启动主程序（带加载界面）
python main.py

# 可视化配方编辑器（独立模式）
python main.py --composer

# 命令行生成配方
python main.py --generate "中心脉冲" "BZ反应模拟" "极光"

# 查看所有模板名称
python main.py --template-list

# 打印模板详情
python main.py --template init       # 初始化公式
python main.py --template evolution  # 演化规则
python main.py --template color      # 颜色映射
```

## 模板系统

模板分三大类，存储在 `templates.py` 的 `FORMULA_TEMPLATES` 字典中。

### 初始化公式（21 个模板）

定义网格初始状态的数学表达式，可用变量：`x`, `y`, `i`, `j`, `random`

| 模板 | 效果 |
|------|------|
| 纯随机、稀疏随机 | 随机初始状态 |
| 中心脉冲、双高斯斑点、多重斑点 | 高斯分布斑点 |
| 正弦条纹、分形噪声v2、Perlin噪声近似 | 纹理/噪声图案 |
| 螺旋波、漩涡场 | 螺旋/漩涡图案 |
| 同心环、莫尔条纹 | 环形波纹/干涉 |
| 棋盘格、钻石格、蜂窝网格 | 几何图案 |
| 梯度、径向渐变 | 渐变 |
| 十字星、闪电分叉 | 线条/分支 |
| 半面激活 | 分区初始 |
| 全零 | 零初始化 |

### 演化规则（22 个模板）

定义每步状态更新的数学表达式，可用变量：`c`, `sum_n`, `avg_n`, `x`, `y`, `t`

| 类别 | 模板 | 特点 |
|------|------|------|
| 经典 CA | Game of Life、Smooth Life | 生命游戏及其平滑版 |
| 反应扩散 | Gray-Scott 简化、斑点、条纹、迷宫 | 图灵图案 |
| 激发介质 | 激发介质、BZ反应模拟、FitzHugh–Nagumo | 螺旋波/靶波 |
| 混沌系统 | 逻辑斯蒂映射耦合、混沌耦合映射、伪Mandelbrot迭代 | 分形/混沌 |
| 扩散/物理 | 纯扩散、竞争扩散、各向异性扩散、对流湍流混合 | 扩散/对流 |
| 现代 CA | Lenia启发式生长、SmoothLife双环 | 类生命形态 |
| 其他 | 相位振荡网络、增长抑制竞争、三次非线性扩散 | 振荡/枝晶/相分离 |

### 颜色映射（17 个模板）

定义 RGB 三通道的颜色映射表达式，可用变量：`v`, `x`, `y`

| 模板 | 色调风格 |
|------|---------|
| 反转灰阶、二值锐化 | 黑/白 |
| 暖色渐变、日落、秋叶 | 暖色调 |
| 冷色渐变、深海、冰川 | 冷色调 |
| 彩虹、绿紫双色、霓虹热感 | 彩色/热力图 |
| 极光、赛博朋克、紫色梦境 | 特殊风格 |
| 金属金 | 金属质感 |
| 位置着色 | 空间位置 hue |

**通过 `--generate` 或编辑器可组合出 21×22×17 ≈ 7,800+ 种配方。**

## JSON 配方格式

```json
{
  "name": "配方名称",
  "version": "1.0",
  "description": "可选描述",
  "grid": {
    "width": 256,
    "height": 192,
    "wrap": true,
    "initial": {
      "type": "formula",
      "expression": "exp(-((x-0.5)**2 + (y-0.5)**2) / 0.02)"
    }
  },
  "neighborhood": {
    "type": "moore",
    "radius": 1
  },
  "evolution": {
    "rule": "c + 0.16*(avg_n - c) + 0.045*c*(1-c) - 0.02*c",
    "variables": ["c", "avg_n"]
  },
  "color": {
    "mode": "per_channel",
    "red": "v",
    "green": "v",
    "blue": "v"
  },
  "tick": {
    "fps": 30,
    "steps_per_frame": 1
  },
  "cycle": {
    "steps": 300
  }
}
```

| 字段 | 说明 |
|------|------|
| `grid.initial.expression` | 初始化公式（变量：x, y, i, j, random） |
| `evolution.rule` | 演化公式（变量：c, sum_n, avg_n, x, y, t） |
| `color.red/green/blue` | RGB 颜色映射（变量：v, x, y） |
| `cycle.steps` | 每 N 步自动重置网格（0=不重置） |
| `tick.fps` | 目标帧率 |
| `tick.steps_per_frame` | 每帧演化步数 |

## 后处理特效

| 特效 | 效果 |
|------|------|
| none | 无特效 |
| bloom | 辉光（高斯模糊叠加） |
| edge | 边缘检测（Sobel 算子） |
| motion_trail | 运动轨迹（历史帧叠加） |
| invert | 反色 |
| vignette | 暗角 |

按 `F` 循环切换特效。

## 项目结构

```
draw/
├── main.py              # 程序入口
├── engine.py            # CA 引擎核心（网格演化、公式编译、颜色映射）
├── renderer.py          # Pygame 渲染器（HUD、特效、侧边栏、加载界面）
├── composer.py          # 可视化配方编辑器
├── recipes.py           # 配方管理（扫描、加载、生成）
├── templates.py         # 数学公式模板库（60 个模板）
├── requirements.txt     # Python 依赖
├── run.bat              # Windows 快速启动
├── NotoSansSC-VF.ttf    # 中文字体
├── effects/             # JSON 配方文件（~64 个）
├── screenshots/         # 截图保存目录
└── README.md            # 本文件
```

## 依赖

- **numpy** — 网格数组运算

- **pygame** — 窗口、渲染、事件处理
- **asteval** — 安全表达式求值
